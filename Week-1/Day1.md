Data - is raw information collected through different sources for storage, processing or analysis.
Information - Processed or Organized data that has meaning and is useful.
Database- Where data is stored in an organized way electronically. Allows easy retrieval,management and updation
DBMS- Software that allows user to define, create, maintain, control access to DB. Acts as an intermediary btw user and database. Ensure data is stored efficiently, retrieved quickly and managed securely.
